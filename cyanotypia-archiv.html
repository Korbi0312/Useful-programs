Small print

Is this private?

No. Anyone with a link can access a file. Do not upload anything confidential.

How long are files kept?

Files are retained while they are being downloaded. Unused files can expire after 45 days.

Do I need an account?

No. This demo keeps the flow anonymous and deliberately short.

Can I use the API?

Yes — the real service can accept simple HTTP uploads. This GitHub demo only simulates the interface.

About this demo

An original file-hosting-style test interface inspired by the sparse structure of modern upload pages. It does not upload or store files; selecting files only previews their names and sizes in this browser tab.
